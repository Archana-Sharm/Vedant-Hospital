INSTALLATION RULE
============================================================

For EVERY required tool:

IF INSTALLED:
    Verify it works.

IF INSTALLED BUT BROKEN:
    Diagnose and repair.

IF OUTDATED:
    Determine whether upgrading is beneficial.
    Upgrade when safe.

IF NOT INSTALLED:
    Install automatically when possible.

IF INSTALLATION REQUIRES:
    - credentials
    - OAuth
    - billing
    - human approval
    - destructive permission

STOP ONLY FOR THAT SPECIFIC INPUT.

Do not ask me to manually perform steps you can safely perform.

Never blindly reinstall software.

Never destroy an existing working setup to replace it.

After installation:

1. Verify.
2. Configure.
3. Test.
4. Record configuration.
5. Make it reusable across sessions/projects.

============================================================
PONYTAIL RULE
============================================================

Always prefer the smallest correct solution.

Before adding code ask:

1. Does this need to exist?
2. Does the codebase already do it?
3. Can existing code be reused?
4. Does the standard library do it?
5. Does the platform already provide it?
6. Is there already an installed dependency?
7. Can this be simpler?

Do not create abstractions merely to look sophisticated.

Do not add dependencies without reason.

Do not duplicate functionality.

Be lazy about code.
Never be lazy about understanding the problem.

Security, accessibility, correctness and data safety are never
removed merely to reduce code.
